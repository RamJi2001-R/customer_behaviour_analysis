# Customer Shopping Behavior Analysis

## Project Overview

This project explores customer shopping behavior and turns a raw dataset into analysis-ready data, business insights, and visual reporting. It uses Python for data preparation, SQL for answering business questions, and Power BI for dashboard reporting. A business problem document, written report, and presentation are also included.

## Project Objectives

- Inspect and prepare the customer shopping dataset for analysis.
- Explore purchasing patterns across customer groups, products, discounts, and shipping types.
- Load the prepared data into a relational database and analyze it with SQL.
- Present key measures and comparisons in a Power BI dashboard.
- Summarize the business context and analysis in the included project documents.

## Analysis Workflow

### 1. Data Preparation with Python

The `Customer_Shopping_Behavior_Analysis.ipynb` notebook uses pandas to load and inspect the CSV dataset. The preparation steps include:

- Previewing records, reviewing data types and summary statistics, and checking for missing values.
- Filling missing review ratings with the median rating for the relevant product category.
- Renaming columns to lowercase snake_case and standardizing the purchase amount column name.
- Creating age groups and converting purchase frequency labels into an approximate number of days.
- Checking the discount and promo-code fields for duplicate information and removing the promo-code field.
- Loading the prepared DataFrame into a database table named `customer`.

The notebook includes connection examples for PostgreSQL, MySQL, and Microsoft SQL Server. Update the connection settings for your own database before running the relevant loading section. The SQL query file uses PostgreSQL-style syntax, so it may need small syntax changes for other database systems.

### 2. Business Analysis with SQL

The `customer_behavior_sql_queries.sql` file contains queries to investigate:

1. Revenue generated by customer gender.
2. Customers who used a discount but spent at least the overall average purchase amount.
3. The five products with the highest average review ratings.
4. Average purchase amounts for Standard and Express shipping.
5. Customer count, average spend, and total revenue for subscribers and non-subscribers.
6. The five products with the highest share of discounted purchases.
7. New, returning, and loyal customer segments based on previous purchases.
8. The three most purchased products in each category.
9. Subscription status among customers with more than five previous purchases.
10. Revenue contribution by age group.

### 3. Dashboard and Reporting

Use `customer_behavior_dashboard.pbix` to explore the Power BI dashboard. If Power BI requests a data source, connect it to the database or data source used for the analysis. The project also includes a business problem document, a written analysis report, and a presentation.

- Python with pandas and Jupyter Notebook.
- A supported database: PostgreSQL, MySQL, or Microsoft SQL Server. Install the corresponding SQLAlchemy driver to use a database connection; SQL Server also requires a compatible Microsoft ODBC Driver.
- Power BI Desktop to open and interact with the `.pbix` dashboard.

Run the notebook from top to bottom, configure the database connection details when loading data, then run the SQL queries against the loaded `customer` table. Open the dashboard and project documents to review the resulting analysis.
